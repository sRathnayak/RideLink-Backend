RIDELINK - RIDE-SERVICE : FULL API LIST + POSTMAN TESTING GUIDE
================================================================================
Project        : ride-service (Spring Boot 3.2.3, Java 21)
Base URL       : http://localhost:5002
Server Port    : 5002 (from application.properties)
Content-Type   : application/json  (for all requests below)
Swagger UI     : http://localhost:5002/swagger-ui.html
Swagger JSON   : http://localhost:5002/v3/api-docs

HOW TO RUN
----------
  Normal DB   : ./mvnw spring-boot:run
  XAMPP DB    : ./mvnw spring-boot:run -Dspring-boot.run.profiles=xampp

IMPORTANT PRE-CONDITION FOR ENDPOINT #1
---------------------------------------
POST /api/rides/create calls the Account Service through OpenFeign BEFORE
returning a response:
    GET http://localhost:5001/api/accounts/{id}
So the account-service MUST be running on port 5001, otherwise you get a
connection error (FeignException / IOException).

--------------------------------------------------------------------------------
[1] CREATE RIDE  (the only HTTP endpoint currently exposed by this service)
--------------------------------------------------------------------------------
METHOD : POST
URL    : http://localhost:5002/api/rides/create
HEADERS:
    Content-Type: application/json
    Accept: application/json

JSON BODY (minimum required):
{
    "userId": 1
}

JSON BODY (full example - all fields the service reads/echoes back):
{
    "userId": 1,
    "passengerId": 1,
    "driverId": null,
    "pickupLocation": "Colombo Fort",
    "dropoffLocation": "Katunayake Airport",
    "fare": 4500.00,
    "status": "REQUESTED"
}

FIELD NOTES
-----------
    userId           (REQUIRED) Long. Used ONLY to call account-service and
                     verify the user exists. Not stored in ride_db.
    passengerId      Long   - maps to entity column (nullable=false if saved)
    driverId         Long   - null until a driver accepts
    pickupLocation   String - required by entity
    dropoffLocation  String - required by entity
    fare             Double - required by entity
    status           Enum   - REQUESTED | ACCEPTED | ON_GOING | COMPLETED |
                              CANCELLED   (defaults to REQUESTED)

SUCCESS RESPONSE (HTTP 200):
{
    "status": "SUCCESS",
    "message": "Ride created successfully!",
    "userData": { ...user object returned by account-service... },
    "rideDetails": { ...your original request body echoed back... }
}

ERROR CASES:
  - account-service not running on 5001 -> 500 with Feign connection error
  - userId missing / not a number        -> 500 (Long.parseLong fails)
  - Wrong URL or method                  -> 404 / 405

NOTE: This endpoint does NOT save anything to the database. It only verifies
the user via Feign and echoes the request back.

--------------------------------------------------------------------------------
[2] OUTGOING API CALL (this service acts as a CLIENT, not a server)
--------------------------------------------------------------------------------
This service calls the Account Service. It is NOT testable from this project's
port - test it on the account-service directly.

METHOD : GET
URL    : http://localhost:5001/api/accounts/{id}
EXAMPLE: http://localhost:5001/api/accounts/1
BODY   : none
DEFINED IN: src/main/java/com/ridelink/ride_service/client/AccountClient.java

--------------------------------------------------------------------------------
[3] SERVICE METHODS THAT EXIST BUT HAVE NO CONTROLLER YET
--------------------------------------------------------------------------------
RideService.java contains these 5 methods, but RideController exposes only
createRide(). The following 4 have NO HTTP endpoint - calling them in Postman
returns 404 until a controller is added.

  Method                                    Repository support      HTTP exposed?
  ----------------------------------------  ----------------------  ------------
  requestRide(Ride)                         save()                  NO (partially - see note)
  getAllRides()                             findAll()               NO -> 404
  getRideById(Long)                         findById()              NO -> 404
  acceptRide(Long rideId, Long driverId)    save()                  NO -> 404
  updateStatus(Long rideId, RideStatus)     save()                  NO -> 404

  note: requestRide() is also not called by the controller.

IF THESE ENDPOINTS ARE ADDED LATER, here are the ready-to-use Postman bodies:

  GET  /api/rides                 -> no body
  GET  /api/rides/{id}            -> no body

  POST /api/rides/request   (body):
  {
      "passengerId": 1,
      "pickupLocation": "Colombo Fort",
      "dropoffLocation": "Kandy",
      "fare": 3200.00
  }

  PUT  /api/rides/{id}/accept  (body):
  {
      "driverId": 10
  }

  PUT  /api/rides/{id}/status  (body):
  {
      "status": "ON_GOING"
  }
  valid status values: REQUESTED, ACCEPTED, ON_GOING, COMPLETED, CANCELLED

--------------------------------------------------------------------------------
[4] DATABASE / ENTITY REFERENCE (ride_db -> table `rides`)
--------------------------------------------------------------------------------
Source: src/main/java/com/ridelink/ride_service/model/Ride.java

  Column            Type         Notes
  ----------------  -----------  -------------------------------
  id                BIGINT       auto-generated (IDENTITY)
  passenger_id      BIGINT       NOT NULL
  driver_id         BIGINT       nullable
  pickup_location   VARCHAR      NOT NULL
  dropoff_location  VARCHAR      NOT NULL
  fare              DOUBLE       NOT NULL
  status            VARCHAR      enum stored as STRING
  created_at        DATETIME     set automatically on insert

  Driver-repository helper queries available (no endpoint yet):
      findByPassengerId(Long)
      findByDriverId(Long)
      findByStatus(RideStatus)
